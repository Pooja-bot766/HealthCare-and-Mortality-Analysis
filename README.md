# HealthCare-and-Mortality-Analysis
This project focuses on analyzing global healthcare indicators using SQL in MySQL Workbench to extract meaningful insights on life expectancy, GDP, population, and regional healthcare performance. Various SQL operations such as filtering, grouping, joins, subqueries, and window functions.

The analysis includes evaluating important indicators such as life expectancy, GDP per capita, population, mortality rate, income level, and regional healthcare performance. Multiple SQL operations such as filtering, grouping, aggregate functions, joins, subqueries, window functions, views, and Common Table Expressions (CTEs) were used to derive actionable insights from the dataset.

This project demonstrates practical SQL skills required for a Data Analyst role, including data querying, business problem solving, trend analysis, ranking, and relational database management.

Key Objectives:
- Analyze healthcare indicators across countries and regions.
- Compare healthcare performance based on life expectancy and GDP.
- Identify countries with high and low healthcare outcomes.
- Perform region-wise and income-level analysis.
- Implement SQL operations from basic to advanced level.
- Build a portfolio-ready SQL case study using real-world healthcare data.

Tools & Technologies Used:
- Database: MySQL Workbench
- Language: SQL
- Dataset: Global Healthcare Indicators Dataset
- Concepts Used: Filtering, Grouping, Aggregate Functions, Joins, Subqueries, Window Functions, Views, CTEs, Data Cleaning
